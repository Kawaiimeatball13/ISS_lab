<h1>Website-ul Noua Agora</h1>
<h2>Website pentru publicarea de articole culturale</h2>

---Features---

<ol>
  <li>Scriere articol (+formatare text)
    <ul>
      <li>cel putin: bold, italic, underline, strikethrough, sub/superscript</li>
      <li>adaugare imagini in articol</li>
    </ul>
  </li>
  <li>Publicare articol</li>
  <li>Modificare stare articol (remove, update)</li>
  <li>Join grup (rol de membru normal sau admin)</li>
  <li>Vizualizare statistici drept admin (+modificare orice articol din grup(?))</li>
  <li>Like-uri si comentarii pentru articole</li>
  <li>Salvare articol la favorite</li>
</ol>
